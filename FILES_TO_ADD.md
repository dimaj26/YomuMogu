# Список файлов, которые необходимо добавить для внедрения исправлений из аудита

Данные файлы отсутствуют в текущем чате, но потребуются для дальнейшей работы:

1. **src/components/ErrorBoundary.tsx** – компонент-обёртка для отлова ошибок рендеринга.
2. **src/components/ErrorFallback.tsx** – UI-заглушка с кнопкой «Повторить».
3. **src/hooks/useApiCall.ts** – хук для единообразной обработки состояний загрузки, ошибки и повторных попыток при `fetch`-запросах.
4. **src/hooks/useApiCall.test.ts** – юнит-тесты для хука.
5. **src/app/error.tsx** – глобальный Error Boundary Next.js (обработка сбоев SSR/CSR).
6. **src/components/__tests__/ErrorBoundary.test.tsx** – тесты для ErrorBoundary.
7. **src/components/__tests__/ErrorFallback.test.tsx** – тесты для ErrorFallback.

## Примечание по текущему `sanitize.ts`

Файл `src/lib/sanitize.ts` уже использует `DOMPurify` для очистки HTML перед вставкой через `dangerouslySetInnerHTML`, все места вставки AI‑контента в чате защищены. Отдельный утилитарный модуль `sanitiseAI.ts` не требуется.

После добавления перечисленных файлов мы сможем:
- Внедрить единую стратегию обработки ошибок,
- Заменить прямые вызовы `fetch` на использование `useApiCall`,
- Обеспечить корректный CSRF‑токен для мутирующих API‑запросов (при необходимости),
- Улучшить доступность и удобство использования интерфейса.
