## 2. Task RNA (логика, риски)
**Логика.** Три точечные правки:
1. **Медиа-баннер** (`MediaInteractivePlayer.tsx:703`): заменить dev-текст «токенизатор не запущен (run-server.bat)» на человеческий, без имени скрипта.
2. **Пустой сайдбар** (`MediaInteractivePlayer.tsx:901-904`): при `tokenizerDown` НЕ показывать «кликните по слову» (слова не кликабельны) — показать нейтральное «разбор недоступен, видео/субтитры работают, вернётся автоматически».
3. **Catch чат-роута** (`api/gemini/sessions/route.ts:40-42`): не отдавать пользователю сырой `error.message` (= «fetch failed») — вернуть человеческий русский текст; сырое исключение оставить в `logger.error` (уже есть).

**Что НЕ делаем (Фаза 2):** контракт `{reason, retryable}`, компонент `ServiceUnavailable`, retry сетевых ошибок, аналогичная санация `grammar-verify` и др. Gemini-роутов. Конфиг-ветку «нет ключа» (`route.ts:7-15`) не трогаем — там уже понятный текст.

**Риски:**
- Тесты, ассертящие старые строки: e2e `media-tokenizer-down` (может проверять `data-testid="tokenizer-warning"` — он остаётся; если проверяет точный текст «run-server.bat» — обновить); тест чат-роута, если ассертит проброс `error.message`. → грепнуть перед правкой.
- `tokenizerDown` уже в области видимости компонента (используется на `:701`) — гейт сайдбара берёт ту же переменную.
